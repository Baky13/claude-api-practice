# Claude API — практика

Практические примеры по курсу **Building with the Claude API** (Anthropic Academy).
Каждый файл — отдельная запускаемая тема, с комментариями на русском.

## Установка

```bash
pip install -r requirements.txt
```

Создай файл `.env` и вставь свой ключ:

```
ANTHROPIC_API_KEY=sk-ant-...
```

> Ключ хранится в `.env`, который добавлен в `.gitignore` и НЕ попадает в репозиторий.

## Запуск

```bash
python 01_basic_request.py
```

## Примеры

| Файл | Тема | Что показывает |
|------|------|----------------|
| `01_basic_request.py` | Базовый запрос | минимум: model, max_tokens, messages |
| `02_multi_turn.py` | Многоходовой диалог | Claude сам не помнит — историю передаём мы |
| `03_system_prompt.py` | Системный промпт | задаём роль и стиль |
| `04_temperature.py` | Температура | 0 = строгий, 1 = креативный |
| `05_streaming.py` | Потоковый вывод | ответ по кусочкам |
| `06_structured_output.py` | Чистый JSON | prefill + stop_sequences |
| `07_tool_use.py` | Использование инструментов | Claude решает вызвать, выполняет наш код |
| `08_prompt_eval.py` | Оценка промптов | модельный грейдер оценивает ответы |

## Задачи на модификацию (углублённо)

| Файл | Задача | Что демонстрирует |
|------|--------|-------------------|
| `09_tool_use_multi.py` | Два инструмента + выбор | Claude сам выбирает нужный инструмент; перебор всех блоков `tool_use` (не только первого) |
| `10_agent_loop.py` | Agent loop | цикл `while`: несколько раундов `tool_use`, пока Claude не даст финальный ответ |
| `11_eval_robust.py` | Хрупкий vs надёжный парсинг | как `stop_sequences=['}']` падает на скобке внутри текста, и как чинить |
| `12_structured_output_robust.py` | Надёжный structured output | через схему: Structured Outputs (`output_config`) и tool use (`input_schema`) — модель обязана вернуть структуру |

## Ключевые выводы

- **Память диалога** — не у Claude, а у нас: передаём всю историю в `messages`.
- **Tool use** — Claude *решает* вызвать инструмент, *выполняет* его наш код.
- **Безопасность** — ключ только в `.env`, никогда в коде/репозитории.
